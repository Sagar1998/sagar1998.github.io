Offence, defence, and the tooling in between.

I currently run vulnerability management and security assessments at Bombay Stock Exchange (BSECL): SEBI‑mandated VAPT/WAPT, NCIIPC and SEBI CSCRF compliance, and the Tenable SC and Nessus platforms that sit underneath it all.

Before that I tested web, API and mobile applications for clients at PwC, delivered analytics and financial due diligence for KPMG Australia, and wrote security tooling at Nomura.
